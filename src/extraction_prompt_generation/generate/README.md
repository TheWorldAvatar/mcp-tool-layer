# generate

Author extraction prompts only. MCP scripts are generated by a separate
chain and are not written here.

| Module | Writes | Author |
| --- | --- | --- |
| [`extraction_prompts/`](extraction_prompts/README.md) | `prompts/<ontology>/EXTRACTION_ITER_*.md`, `PRE_EXTRACTION_ITER_*.md`, `*.materializable.inc` | Exact-edits for `.md` (default `gpt-5`); compiler for `.inc` |

Prompt contracts live in [`extraction_prompts/contracts/`](extraction_prompts/contracts/README.md).
The shared exact-edits runner is `authoring.py`. `artifact_state.py` is
checkpoint infrastructure, not a second generation method.

There is no KG-building prompt track and no ONEPASS prompt track.

## Shared authoring modules

| File | Role |
| --- | --- |
| `authoring.py` | Sequential / parallel exact-edits loop for one track |
| `authoring_parallel.py` | Isolated `ProcessPool` waves for independent empty slots |
| `authoring_task.py` | Per-artifact model task JSON (role, contract, guidance) |
| `authoring_progress.py` | Terminal progress lines and focused validation projection |
| `artifact_state.py` | Resume journal (`generating` / `passed` / `failed`) |
| `artifact_surface.py` | Read generated `__all__` manifests without importing them |
| `prompt_semantic_review.py` | Model semantic review of one authored `.md` |
